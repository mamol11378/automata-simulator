# شبیه‌ساز ماشین متناهی

پروژه درس نظریه زبان‌ها و ماشین‌ها در مقطع کارشناسی مهندسی کامپیوتر.

امکانات فعلی:
- شبیه‌سازی گرافیکی DFA
- اجرای رشته به صورت کامل یا مرحله‌به‌مرحله
- جدول انتقال
- رابط فارسی و انگلیسی
- طراحی تیره و دانشگاهی
- بخش آماده برای تبدیل NFA به DFA

اجرا:
```bash
pip install -r requirements.txt
python main.py
```
