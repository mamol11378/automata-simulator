# Automata Simulator

A bilingual desktop application for a Bachelor's Computer Engineering project on Formal Languages and Automata Theory.

## Features
- DFA visual simulator
- Step-by-step string execution
- Transition table
- Interactive state/transition designer
- Persian / English UI
- Dark academic interface
- NFA → DFA section reserved for the next phase

## Run
```bash
pip install -r requirements.txt
python main.py
```
